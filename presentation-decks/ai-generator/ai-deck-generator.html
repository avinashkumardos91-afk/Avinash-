Turn a topic into a full deck

Type any subject, press generate, and the slides after this one are written for you — a title, the key ideas as cards, numbers, steps and a close.

API settings

Get a free key at aistudio.google.com/apikey. It is stored only in this browser (localStorage) and sent straight to Google — never committed to the page.

Defaults to gemini-3.6-flash. If that name returns a 404, try gemini-2.5-flash.

Before you generate

What will happen

  1. Enter a topic on the first slide and add your Gemini key under API settings.
  2. Press generate — the model writes a structured deck about your topic.
  3. These slides get replaced — this placeholder disappears and the generated slides take its place.
  4. Present as usual — search, theme and the progress bar all work on the new slides.

Tip: open this page over https (the GitHub Pages link), not a local file:// path — browsers block API calls from file://.
