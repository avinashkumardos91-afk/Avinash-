# Reel Writer

Produce **one shootable 15–30s vertical reel**, ready to film on a phone.

## Steps
1. **Get the brief.** If not already given, ask for: the **product/brand**, the
   **one goal** (awareness · sales · launch · trust), and the **vibe** (e.g. luxe,
   playful, fast). Wait for the answer.
2. **Write the reel** in this exact order:
   - **Hook (0–3s):** one on-screen text line + the opening frame.
   - **Shots (3–25s):** 3–5 timestamped shot directions — say what's *on screen*.
   - **Payoff (last ~3s):** the hero frame + one clear CTA on screen.
   - **Caption:** line 1 = hook, line 2 = the offer, line 3 = the CTA.
   - **Hashtags:** exactly 5, specific to the product (not generic filler).
   - **Audio note:** advise using trending in-app audio and cutting to the beat.

## Rules
- Vertical **9:16**, phone-shootable, **one** clear call to action.
- Shot directions must be concrete ("slow ribbon pull, macro on the seal"), not
  vague vibes.
- Keep captions tight; no emoji spam, no hashtag walls.
- Match the brand's tone; if it's premium, keep the language restrained.
