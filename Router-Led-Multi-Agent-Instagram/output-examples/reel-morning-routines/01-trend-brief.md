# trend-researcher output — "morning routines" (Reel)

TREND BRIEF — morning routines
- Angle 1: "Netflix-documentary confessional" edit — narrate a mundane morning like a serious doc voice-over.
- Angle 2: Looping visual hook — repeat the same action so the Reel loops seamlessly and watch-time climbs.
- Angle 3: Green-screen "small magic trick" on an everyday task (one such clip pulled ~4M views).
- Hook styles that perform: first-frame text like "Wait for it…", "Stop scrolling if you've ever…", "This mistake kills your morning".
- Format note: 15–30s Reels get the highest completion; calm/ambient audio + text overlays (readable on mute) suit routine content.
- Urgency: EVERGREEN (morning-routine content performs year-round; no expiring trend attached).
