# Riwaazbox · Multi-Platform Content Playbook

`riwaazbox-multi-platform-deck.html` — 16 slides. Double-click to present; no build
step, no dependencies.

Built from [`../template/deck-template.html`](../template/deck-template.html), so it
carries the same three features: theme toggle (<kbd>T</kbd>), search
(<kbd>/</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd>), and the progress bar / dots / counter.

## The argument

Four platforms, four different jobs — nothing gets posted until you can name which
job it is doing.

| Platform | Job | Primary CTA |
| --- | --- | --- |
| Instagram | create the want | DM to order · link in bio |
| YouTube & Shorts | catch the search | link in description |
| LinkedIn | open bulk / corporate orders | DM for the rate card |
| WhatsApp & Web | close the order | confirm and pay |
